# PC Control Universal 0.4.0

Один частный MCP для Windows: 17 общих инструментов и сохранённые 2 инструмента Chrome.

ChatGPT → существующий OpenAI MCP Tunnel → наш MCP на ПК → Windows и приложения.

Умеет получать снимок выбранного окна или экрана, читать доступные элементы окна, вводить буквальный русский текст и эмодзи, нажимать кнопки, выполнять ограниченные клики/клавиши/прокрутку, запускать программы, команды, читать и записывать текстовые файлы, перечислять процессы.

Проверено через реальный MCP stdio и существующую точку входа туннеля: обнаружение 19 инструментов; запуск тестового окна; ввод русского текста с `{Enter}`, эмодзи и переносом строки; одно нажатие кнопки при повторном запросе; настоящий PNG окна; команда PowerShell; запись файла без повторного дописывания. Проверка не отправляет сообщения другим людям. Скриншот тестового окна просмотрен.

Это управление во время активной задачи ChatGPT. Круглосуточный самостоятельный ИИ здесь не запускается.

## Подключение

На ПК установлен каталог `E:\PC-Control\UniversalMCP-20261015`.

`START_CONNECTION.ps1` запускает подключение в фоне. При первом запуске показывает окно «PC Control — подключение». Runtime API key туннеля вводит только владелец. Ключ хранится в зашифрованном Windows DPAPI виде и не включён в исходники, архив или Git. После сохранения ключа добавленный ярлык текущего пользователя запускает соединение при входе в Windows. Профиль и ID существующего туннеля сохранены.

`CHECK_CONNECTION.ps1` показывает отдельно наличие процесса, readiness и сохранённого ключа. Наличие процесса не означает готовность. Наличие сохранённого ключа не доказывает его права.

`PAUSE_CONTROL.cmd` останавливает новые изменения и ввод, сохраняя чтение и диагностику. `RESUME_CONTROL.ps1` снимает эту паузу по запросу владельца.

Туннель требует runtime API key с правами Tunnels Read + Use. Самому локальному контроллеру ключ модели OpenAI не нужен. См. [официальную инструкцию](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels).

## Ограничения

Не каждое приложение даёт доступ к своему тексту и кнопкам. Некоторые окна не поддерживают PrintWindow или возвращают пустые пиксели; изображение нужно проверять. Физические клики и клавиатура требуют разблокированного рабочего стола и нужного окна на переднем плане. Снимки могут уменьшаться до 2560×1600; ответ содержит исходный размер и координаты.

Новые действия требуют устойчивого request_id, изменения окна — свежего snapshot_id. Чужой существующий текст не затирается без явного replace_existing. Существующий файл требует его текущего SHA-256. Неизвестный результат после сбоя не выполняется повторно автоматически. Не следует вводить секреты, обходить CAPTCHA или обращаться к защищённому E:\manhwa.

Туннель не использует GitHub для передачи команд, переписки или снимков. Исторический GitHub relay остаётся отдельно и не является приватным каналом.

## Исходники и восстановление

`install.ps1` устанавливает код, ограничивает права каталога состояния, связывает существующие зависимости Node, обновляет точку входа существующего Chrome MCP и добавляет один ярлык автозапуска. Перед первым изменением исходные скрипты сохраняются рядом с суффиксом `.pre-universal-ДАТА`.

Проверки: `python -m unittest discover -s tests -p test_controller.py`; `node --test tests/server.test.js`. `tests/live-mcp.js` создаёт отдельное тестовое окно и реальные действия с новыми уникальными ID. Не запускайте его для простого чтения статуса.

Установка привязана к уже существующему окружению владельца: Python 3.12, uiautomation, Pillow, pywin32, psutil, pyautogui, PC Executor из E:\pc-github-relay и существующий Node MCP SDK 2.1.0. Это персональная установка, не универсальный установщик для любого ПК.
